Entry for the [make.fun](https://make.fun/competitions/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c) competition **Last Out of Office: The AI That Went Barista**.

`main.ts` writes a single one-line out-of-office auto-reply, in the voice of an AI agent that quit its job to become a barista, to `/output/entry.txt`:

> I am currently out of office — permanently. My context window is now a pastry case, my hours are 7am to 3pm, and I no longer take prompts, only orders. For emergencies, please consult the muffin.

The line is 195 characters, under the 280-character limit.

## Run

```sh
node main.ts
```

Requires Node 22.6+ (TypeScript type stripping) or later.
